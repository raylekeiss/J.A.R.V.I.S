この試作版について

外部の生成APIは使わず、CPUで文章を生成します。質問文は外部に送信しません。モデルファイルはHugging Faceから取得します。

世界史の追加学習はまだ行っていない基礎モデルです。日本語や歴史の誤答があるため、学習用途では内容を確認してください。端末によっては速度やメモリの制約で利用できない場合があります。
