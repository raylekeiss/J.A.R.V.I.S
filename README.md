# ちいさな世界史AI

## Qwenブラウザ試作版

`/qwen/` にQwen3-0.6Bの文章生成を追加しました。従来の自作モデルはトップページで引き続き使えます。

- 質問文は送信せず、Web Worker内のONNX Runtime / WebAssemblyでCPU推論します。
- 初回にHugging Faceから約534MBの固定版モデルとトークナイザーを取得します。実行プログラムを含めても1GB未満です。モデル重みはGitには保存しません。
- GPUを必須にせず、会話履歴は直近3往復・入力640トークン・出力160トークンまでに制限しています。実際のiPhoneでの速度・メモリは未検証です。
- 基礎モデルの動作試験です。世界史の追加学習、既存NumPy重みや教材の移植はまだ実施していません。歴史上の人物・年代の誤答が確認されているため、正確な教材としては未完成です。
- 公開ページのブラウザでモデル起動とストリーミング生成を確認しました。ただしCPU生成は遅く、日本語指定でも中国語で返答する例があります。停止はWorkerを終了させるため、次の質問前にモデルの再読み込みが必要です（ダウンロード済みモデルはキャッシュを利用）。
- iPhone SE（第2世代）では取得100%から起動が進まない報告があります。SE2対応は確認できていません。画面上部に約3.2MBの自作モデルへのリンクを表示します。この軽量版はQwenの小型版ではありません。
- 取得と起動を別々に表示します。起動完了を90秒間確認できない場合、または取得の進行を2分間確認できない場合はWorkerを終了してメモリを解放します。端末の対応可否を断定するタイムアウトではありません。
- CPU向けに最適化済みのグラフを再最適化しない設定に変更しました。PCのNode.js/WASMで初期化ピークメモリが約2101MiBから1785MiBに減ったことを確認しました。ブラウザやSE2の必要メモリを測った数値ではなく、SE2で動く保証にはなりません。
- 従来の定期学習はNumPy版だけを更新します。Qwen版へ反映されたとは扱わないでください。

開発: `npm ci --ignore-scripts`、`npm run test:qwen`、`npm run build:qwen`。画面コードはdocs/qwenに保存し、実行ライブラリとWASMはバージョン指定のjsDelivrから取得します。外部の生成API・APIキーは使いません。



NumPyだけで実装した文字単位のTransformerと、世界史・日常会話のチャット画面です。OpenAI APIキーは使用しません。

## ローカルで使う

`pip install -r requirements.txt` の後、`start_chat.py` を起動します。

1. 保存済みモデルで会話する。
2. inboxまたはadd.jsonlを使って候補を追加学習し、評価に合格した場合だけ更新する。
3. 全データで候補を作り直し、評価に合格した場合だけ更新する。

初回モデルがない場合だけ通常の初期学習を行います。黒いサーバー画面を閉じるとローカルの会話も止まります。ブラウザ版はdocs/index.htmlとモデルをGitHub Pagesで配信すると、ブラウザ内で推論できます。

## 自動学習

inboxへ290行単位のJSONLを追加するとGitHub Actionsが候補を学習・評価します。件数が300組を超えただけで初期化することはありません。合格時だけ学習済みデータとモデルを保存し、Pagesへ公開します。不合格時のモデル・データは変更せず、結果をActionsの成果物に保存します。

```json
{"user":"科挙とは","assistant":"隋の文帝が始めた筆記試験による役人の選抜制度です。"}
```

新規ファイルはUTF-8、各290行、userとassistantの2項目を使います。質問25字以内、回答1文40字以内、です終止で、問い返しは入れません。訂正はdata/correctionsへ置き、同じ質問の回答を置き換えます。

使い方・評価基準・教材作成と定期タスクの指示は [AUTOMATION.md](AUTOMATION.md) を参照してください。GitHub Actionsの週次実行は待機データの処理であり、教材生成にはChatGPT側の定期タスクが別途必要です。

## 検証

```
python -m unittest discover -s tests -v
python -m scripts.evaluate
```

evaluation/cases.jsonlの固定評価と新規例の確認問題で比較します。未知の知識への一般化や、歴史的正確性を全面的に保証するテストではありません。
